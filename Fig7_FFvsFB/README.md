# Feedforward and feedback motifs

From this extracted folder, run `python -m pip install -r requirements.txt`, then `python -m jupyterlab FF_vs_FB_FINAL_PLOTTING.ipynb`. Select Run All Cells to save eight PDF panels under figures/. The supplied cache uses tau_2 = 2 for the feedforward triangle-count sweep. To recompute after editing model parameters, set force=True in the final plotting cell. This replaces the bundled cache locally.
